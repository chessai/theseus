# ADR-0024: PDK and device models

**Status:** Accepted

## Decision
- **B2.1** Sky130A: real measured foundry models, first-class ngspice
  support, largest open community, cheap shuttle path if M5 happens;
  130nm's low leakage is genuinely favorable for slow-ramp adiabatics.
  Recorded alternates: IHP SG13G2 (named alternate if shuttle logistics
  favor it -- avoid Sky130-isms where free); PTM rejected (no silicon
  path); GF180 rejected (coarser node, thinner analog documentation).
- **B2.2** PDK pinning is a reproducibility requirement: PDK version
  (open_pdks/volare) pinned in the flake like the Rust toolchain; every
  characterization result stamped with PDK + simulator versions.
  Unstamped numbers cannot exist in the system.
- **B2.3** 1.8V core FETs. Vt flavor {std, lvt, hvt} and body config
  (NMOS body-to-rail baseline vs deep-n-well isolated) are
  **characterization axes, not pre-decisions** -- T-gates want low Ron
  (lvt) but slow ramps punish leakage (hvt); the answer is empirical and
  possibly per-role. Deliverable: a measured answer to "what does body
  effect cost a Sky130 T-gate at mid-swing" (no public literature known).
- **B2.4** Full-rail 1.8V, 27°C, tt corner for M3a. Reduced swing and
  ss/ff corners are roadmap lines (reduced swing interacts superlinearly
  with adiabatic losses).
