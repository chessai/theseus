# ADR-0030: TISC-1 — ISA principles

**Status:** Accepted

## Decision — principles ratified, encodings deferred
- **P1** Every instruction denotes an iso on State; the decoder is a
  Branch tree on opcode bits — **the coverage checker enforces ISA
  totality**: undefined opcodes are a compile error in the CPU's own
  source until explicitly mapped.
- **P2** All data writes are merges or exchanges: +=, -=, ^=, rotates,
  controlled swap, EXCH. No destructive MOV; XORI/ADDI instead of
  load-immediate; shifts out (they erase), rotates in.
- **P3** Control flow via **PC-exchange** (Pendulum SWAPBR lineage):
  branching swaps a branch register with the PC offset — control flow is
  itself an exchange; come-from stays recomputable; paired-branch
  assembly mirrors clause coverage.
- **P4** InstrReg transiently populated (fetch–execute–unfetch,
  ADR-0029); provably zero between steps; acts only as control.
- **P5** Sizes by energy budget: W=8, 8 registers, 16-bit instruction
  words, scratch per ADR-0029-A. **Opcode encodings are an
  implementation-time document** — ratifying maps now is planning
  theater.

## D3 workloads
**Fibonacci** (classic reversible demo; loops + arithmetic; ~step
un-executing it is maximally legible) and a **Feistel cipher round**
(XOR-based, in-place, the energy workload; gestures at C3.4's DPA note).

## The structural caveat, named
Running T steps = iterating step; the backend is unroll-only. **M4-v1 is
an unrolled-T machine** (T ≈ 16–64): the temporal/spatial duality made
literal — a CPU is an un-specialized spatial circuit; specializing step
to a fixed ROM constant-folds the CPU into the program's circuit (theory
note). The recirculating CPU everyone imagines is exactly C2.4's parked
work — **M4 formally declares C2.4's wake condition**; M4-v2 is the ring
machine. Risk register: ~150 State bits ≈ 300 rails riding buffers every
tick — C3's static report makes this exact before anything is built.
